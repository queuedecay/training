# Training Walkthroughs

This folder contains **trainer-facing** step-by-step guides for each section of the
*GitHub for Developers* course. Work through them in order during the 2-hour session.

## How to use these files

- Open the relevant file a few minutes before each section.
- Follow the **Demo steps** and **Talking points** in sequence.
- Use the **Exercises** to give participants hands-on practice.
- **Estimated times** are shown at the top of each file — keep an eye on the clock.

## Quick-start checklist (do this the day before)

- [ ] Run the **Setup Training Environment** workflow (Actions tab → run manually)
- [ ] Verify issues and PRs were created (check the Issues and Pull Requests tabs)
- [ ] Create a GitHub Project board named *OctoTasks Sprint 1* and add open issues
- [ ] Enable GitHub Pages (Settings → Pages → Source: GitHub Actions)
- [ ] Enable branch protection on `main` requiring the `Test` CI job to pass
- [ ] Push wiki content (`wiki/*.md`) to the `.wiki` repository
- [ ] Share the GitHub Pages URL with participants
- [ ] Clone the repo and confirm `npm start` works locally
