GitHub Developer Training

A hands-on 2-hour workshop for developers migrating from Gerrit & Jenkins to GitHub.

⏱ 2 hours 👥 ~100 developers 🚀 Beginner friendly

About This Training

This course gets developers productive on GitHub as quickly as possible by pairing hands-on exercises with the OctoTasks web app — a simple task manager that participants browse, modify, and ship during the session.

📂 The App

OctoTasks is a lightweight Node.js/Express task manager. Its source lives in src/ and is simple enough to understand in minutes.

Training Agenda

Time Section Topics
0:00 – 0:10 Welcome & Objectives What changes from Gerrit → GitHub; what we'll build today
0:10 – 0:25 Navigating GitHub UI tour; repositories, issues, PRs; code browsing; history
0:25 – 0:45 Repository Basics Repo structure; commits, branches, PRs; Gerrit vs GitHub workflows
0:45 – 1:05 GitHub Flow Branching strategy; PR lifecycle; reviews; merging
1:05 – 1:10 GitHub Copilot & AI Conceptual overview; code generation, refactoring, test creation
1:10 – 1:25 GitHub Actions — Demo CI/CD concepts; workflow walkthrough; integration with PRs
1:25 – 1:40 Putting It All Together End-to-end flow: code → PR → review → CI → merge
1:40 – 1:45 Wrap-Up & Next Steps Key takeaways; follow-up workshops; Q&A

Learning Outcomes

🔀 GitHub Flow

Participants will confidently create branches, open pull requests, respond to review comments, and merge.

🤖 GitHub Actions

Participants will understand how CI/CD pipelines are triggered and how checks gate merges.

🗂️ Project Management

Participants will use Issues, a GitHub Project board, and labels to track work.

🔍 Code Review

Participants will leave inline comments, suggest changes, and approve pull requests.
