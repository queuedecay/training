Setup Guide

Follow these steps to prepare the repository for a training session.

Prerequisites

  • A GitHub account with Admin access to this repository
  • Git installed locally (git --version)
  • Node.js 20+ installed (node --version)
  • GitHub CLI installed (gh --version)

1 — Clone & install

git clone https://github.com/<org>/training.git
cd training
npm install

2 — Run the app locally

npm start
# → OctoTasks running on http://localhost:3000

Open http://localhost:3000 in your browser. You should see the task-manager UI with five seed tasks.

3 — Run the test suite

npm test

All 16 tests should pass and a coverage/ folder is generated.

4 — Enable GitHub Pages

  1. Go to Settings → Pages in this repository.
  2. Under Source, select GitHub Actions.
  3. Push any change to docs/ — the Deploy to GitHub Pages workflow will run and publish the site.
The Pages URL will be https://<org>.github.io/training/. Share this with participants before the session.

5 — Seed training data (issues, PRs, project)

A one-click workflow creates realistic issues and pull requests for the training demos.

  1. Go to Actions → Setup Training Environment.
  2. Click Run workflow.
  3. Enter the cohort name (e.g. Cohort 1) and click Run workflow.

The workflow will create:

  • 4 closed issues (background history)
  • 4 open issues (bugs and features to fix during training)
  • 1 open pull request (feature in progress)
  • 1 merged pull request (completed feature)

6 — Create a GitHub Project board

  1. Go to the Projects tab in this repository.
  2. Click New project → Board.
  3. Name it OctoTasks Sprint 1.
  4. Add the open issues to the board under To Do.

Walk participants through the board during Section 2 (Navigating GitHub).

7 — Configure branch protection

  1. Go to Settings → Branches → Add branch ruleset.
  2. Target the main branch.
  3. Enable: Require a pull request before merging and Require status checks to pass.
  4. Add the Test CI job as a required check.

8 — Set up the Wiki

Wiki content is stored in the wiki/ folder. To publish it:

# One-time: enable the Wiki in Settings → Features → Wikis
git clone https://github.com/<org>/training.wiki.git /tmp/wiki
cp wiki/*.md /tmp/wiki/
cd /tmp/wiki
git add . && git commit -m "Add training wiki pages" && git push
You're ready! The repository now has seed issues, pull requests, CI checks, GitHub Pages, and a project board — everything needed for a productive 2-hour training session.
